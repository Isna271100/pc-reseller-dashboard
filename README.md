# PC Reseller Hub

A simple pastel photocard reseller dashboard that runs in your browser.

## Included
- Photocard inventory (member, group, album, code, price, stock status)
- Order tracking (buyer, item, amount, payment/shipping status)
- Customer book
- Shipping tracker
- JSON backup export

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or another modern browser.
3. Your entries are saved in that browser on that device.

## Publish with GitHub Pages
1. Create/sign in to your GitHub account.
2. Create a new public repository (for example `pc-reseller-dashboard`).
3. Upload `index.html` and `README.md` to the repository's main branch.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
6. Wait for the Pages URL to appear in Settings → Pages.

## Important
This starter version stores data in the browser's local storage. It does not sync between devices or users. Use **Export backup** regularly and keep the downloaded JSON file safe.
